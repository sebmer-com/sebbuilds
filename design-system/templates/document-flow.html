Continuous report / Template

Evidence that flows with the argument.

Abstract

This variant is for long reports whose sections must continue across automatic browser-created pages. A4 margins are supplied by the named page rule, while simulated running headers and folios are disabled.

01

Begin with the decision context

State the audience, decision, evidence standard, and practical consequence before presenting detail. The opening should let the reader understand why the document exists and what a useful outcome looks like.

Keep facts, interpretations, and recommendations distinguishable. Cite claims near the sentence or figure they support. Move complete reference metadata to an appendix only when that improves reading.

02

Structure the evidence as an argument

Use major sections for changes in reasoning, not merely changes in source material. Strong rules introduce those sections. Hairlines separate comparable rows and supporting records.

Long sections may now break naturally across A4 pages. The heading remains attached to the first following paragraph, while figures, tables, and callouts retain their own break protections.

03

Compare formats without changing the grammar

Web publications, slides, and PDF reports use different dimensions, but the same hierarchy. Serif typography carries ideas and narrative. Sans-serif typography carries metadata, labels, sources, and controls.

04

Use figures as evidence

Every figure needs a purpose, caption, and source. Grayscale is the default. Retain color only when it carries data meaning, and mark that exception explicitly with the evidence-color modifier.

Decoration never substitutes for a missing relationship or claim.

05

End with the consequence

State what the evidence changes, what remains uncertain, and which action follows. A conclusion should advance the decision rather than repeat every section heading.
